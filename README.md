# css-pseudo-classes
A frontend project demonstrating the practical use of CSS pseudo-classes to create dynamic and interactive user interfaces.

What I learned today: Nov, 1st 2026
 ## 🧠 What I Learned Today

Today, I focused on mastering **CSS Pseudo-Classes** and **Pseudo-Elements** to make static webpages interactive and dynamic. Here are the core concepts I practiced in my code:

* **Interactivity (`:hover`):** I learned how to use user-triggered states. I applied this to my `.card:hover` selector so that when a user moves their mouse over the card, it changes its background color to `khaki` and smoothly pops out.

* **Smooth Animations (`transition`):** I paired my pseudo-classes with the `transition: transform` property. This prevents the card from changing sizes instantly, making the `scale(1.1)` resizing look fluid and professional.

* **Structural Styling (`::before`):** I explored pseudo-elements like `h1::before` to dynamically inject decorative content directly before my headers using pure CSS, keeping my HTML clean.
